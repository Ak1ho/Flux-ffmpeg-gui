# 项目上下文

- 产品：流转 · Flux，Windows PySide6 桌面媒体处理工作台。
- 素材是导入列表中的文件；选择集决定本次入队范围。无选择时沿用当前处理类型的可见素材回退行为。
- 任务由输入文件、媒体类型、操作和参数快照组成；普通批量每个素材创建一个任务，合并操作创建一个多输入任务。
- `studio/ui.py` 负责导入、选择和队列展示，`studio/tasks.py` 负责调度，`studio/engine.py` 负责处理。
- 设计与使用资料：`DESIGN-linear.app.md`、`README.md`、`使用说明.md`。目前没有独立 CONTEXT.md 或 ADR 体系。
- 当前交付目录没有配置 Git 仓库、远程 issue tracker 或 triage 标签。诊断结果以测试和发布说明留存，不假定外部 issue 系统可用。
- 测试使用隔离状态目录，不操作用户原始媒体、运行任务或安装目录。交付新版采用独立版本目录，不强制关闭旧版。
